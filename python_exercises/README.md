# Решения упражнений 1–11

Запускайте каждую программу отдельно, например:

```bash
python3 exercise_01.py
```

Для № 9–11 положите input.txt в текущую рабочую папку. Кодировка UTF-8. № 10 и № 11 сохраняют результат в output.txt и перезаписывают его при повторном запуске.

## Упражнение 1

XOR двух одинаковых чисел равен нулю. Применяем XOR к числам от 1 до n и к оставшимся карточкам: останется потерянная. Создаётся только список входных данных. Можно ввести все числа в одной строке или n отдельно, а затем карточки.

## Упражнение 2

Длина группы равна len(text) // g. Разворачиваем каждую группу срезом [::-1], затем соединяем. Введите G и строку через пробел. Во втором примере условия ошибка: при G = 6 длина группы равна 4, поэтому правильный результат — T0BA0LEANANAE0BAS0OVNANA.

## Упражнение 3

Обычный палиндром проверяем сравнением с обратной строкой. Для зеркальности сравниваем отражение каждого символа с символом на противоположном конце. Пары E↔3, J↔L, S↔2, Z↔5 работают в обе стороны. Символ 0 не входит в таблицу отражений.

## Упражнение 4

Меняем местами элементы с индексами 0 и 1, 2 и 3 и так далее. Последний элемент нечётного списка остаётся на месте. Здесь ровно три строки кода, включая ввод и вывод.

## Упражнение 5

Последний элемент переносим в начало вывода, затем выводим остальные. Здесь ровно две строки кода.

## Упражнение 6

count считает вхождения числа. Печатаем только числа с одним вхождением, сохраняя исходный порядок. Исходный список не меняем, вспомогательных списков, строк и срезов при обработке нет. Время O(n²), дополнительная память O(1). Пробел после последнего числа допустим для обычной проверки по числам.

## Упражнение 7

Сохраняем число с наибольшей частотой. При равенстве частот останется первое из них. Список предполагается непустым. Ограничения на обработку списка соблюдены; время O(n²), дополнительная память O(1).

## Упражнение 8

У медианы ровно n // 2 меньших элементов, поскольку все числа различны. Для каждого кандидата подсчитываем число меньших. Список не изменяется, дополнительных списков нет. Время O(n²), дополнительная память O(1).

## Упражнение 9

Считаем группы подряд идущих знаков .!?: многоточие и сочетание ?! считаются одним окончанием. Предполагаем, что предложения заканчиваются этими знаками и точки не используются в сокращениях. Условие не задаёт правила для сокращений и текста без завершающего знака; такой незавершённый фрагмент этот вариант не учитывает.

## Упражнение 10

Добавляем «с» и гласную после одиночной гласной либо после гласной, непосредственно перед которой стоит согласная. Поэтому начальная группа «ао» в слове «аорта» остаётся без вставки. Оригинальные символы сохраняются, добавленный слог записывается строчными буквами. Результат выводится и сохраняется в output.txt. В примере для «паэлья» есть несогласованность: по правилу повторения гласной получается «пасаэльяся», а в условии дано «пасаэльяса».

## Упражнение 11

Простейшая цепь Маркова первого порядка: для каждого слова запоминаем слова, которые шли после него в учебном тексте. Повторения в списке переходов сохраняются, поэтому частые переходы выбираются чаще. Генерируем до 50 слов, останавливаясь, если продолжений нет. Пунктуация остаётся частью слов; связность и завершённость предложений не гарантируются. Идея описана в материале задания: https://tproger.ru/translations/markov-chains. Результат сохраняется в output.txt.
