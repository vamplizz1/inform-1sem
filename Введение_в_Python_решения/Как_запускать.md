# Введение в Python — решения

Запускайте программы отдельно. Например:

```bash
python3 01_Калькулятор.py
```

Для № 4 и № 6 создайте input.txt в папке, из которой запускаете программу. output.txt перезаписывается. Эти имена сохранены по условию задания; названия решений — на русском.

## 01_Калькулятор.py

Введите a и b на отдельных строках. Поддерживаются дробные числа; десятичный разделитель — точка.

## 02_Последняя_цифра.py

Остаток от деления натурального числа на 10 — его последняя цифра.

## 03_Среднее_геометрическое.py

Введите числа через пробел. Среднее геометрическое — корень степени n из произведения n чисел. Используем обычное определение для неотрицательных чисел. Это учебный вариант для чисел умеренной величины.

## 04_Калькулятор_в_файл.py

В input.txt первая строка содержит числа, вторая — +, - или *. Выполняем действие слева направо: 10 - 3 - 2 = 5. Результат записывается в output.txt. Предполагается корректный непустой ввод.

## 05_Системы_счисления.py

Введите запись N, исходное основание b и новое основание c. Основания — от 2 до 10. Например: 1011 2 10 → 11. int(n, b) переводит запись в число, затем остатки от деления на c дают цифры результата.

## 06_Сложный_калькулятор.py

В input.txt: числа, затем операция, затем основание — каждая часть на своей строке. Поддерживаются основания 2–36, отрицательный результат и ноль. Вычитание выполняется слева направо. Результат записывается в output.txt; для цифр выше 9 используются A–Z.

## Пример для № 4

input.txt:
```text
10 3 2
-
```
Результат: 5.0

## Пример для № 6

input.txt:
```text
101 11
+
2
```
Результат: 1000
