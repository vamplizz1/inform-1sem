# Функции, рекурсия и NumPy — решения

Восемь отдельных программ, включая дополнительное упражнение № 8.

Установка NumPy (для № 5–8):
```bash
python3 -m pip install numpy
```

Запуск из папки с решениями:
```bash
python3 01_Число_Фибоначчи.py
```

## 01_Число_Фибоначчи.py

Используем нумерацию F₀ = 0, F₁ = 1. Функция последовательно вычисляет числа, сохраняя только два последних. Введите N. Пример: 10 → 55.

## 02_Простые_множители.py

Делим число на каждый возможный простой множитель, пока оно делится без остатка. Повторяющиеся множители выводятся несколько раз. Пример: 60 → 2 2 3 5. Для 1 список множителей пуст.

## 03_Расширенный_алгоритм_Евклида.py

Рекурсивный расширенный алгоритм Евклида даёт одно решение. Все остальные имеют вид x = x₀ + (b/d)k, y = y₀ − (a/d)k. Проверяем целые k около точек, где x или y меняет знак. Выбираем минимальную сумму модулей, затем минимальный x. Введите по паре a b на строку. Для завершения ввода в Терминале нажмите Ctrl+D на пустой строке.

## 04_Треугольник.py

Введите размер и символ через пробел, например 7 c. Ширина строк: 1, 2, 3, 4, 3, 2, 1, как на рисунке. Для чётного размера две центральные строки имеют одинаковую ширину.

## 05_Спиральная_матрица.py

Введите N M через пробел. Заполняем матрицу числами от 1 по часовой стрелке, начиная с верхнего левого угла. Умножаем каждую строку на её индекс: 0, 1, 2, …, как на рисунке. Поэтому первая строка результата — нули. np.arange(n)[:, None] превращает индексы в столбец для broadcasting.

## 06_Коэффициенты_МНК.py

Ищем прямую y = ax + b. Введите значения x через пробел в первой строке, соответствующие y — во второй. Вывод: a b. Пример: x = 0 1 2, y = 1 3 5 → 2.0 1.0. Сумма квадратов отклонений от этой прямой минимальна.

## 07_Линейная_система.py

Введите N M, затем N строк по M чисел. Последний столбец — правые части, переменных M−1. При единственном решении выводятся значения переменных. При бесконечном числе решений выводятся частное решение и базис для всех решений. При несовместности выводится сообщение. Используется численный метод с погрешностью: почти вырожденные системы требуют осторожной интерпретации.

## 08_Генератор_данных_для_МНК.py

Введите N a b через пробел. Выводятся N строк с парами x y. Сначала генерируем гауссовский шум, затем убираем из него среднее и линейный тренд. Поэтому МНК восстанавливает заданные a и b с точностью вычислений, а не только приблизительно в среднем. Скорректированный шум уже не независим; sigma задаёт исходный разброс. При N = 2 точки лежат точно на прямой.
